# #77 FVE configuration and annual yield estimate (plan)

Parent: #20. Scope excludes approval and linking to a quote (#78).

## Decisions
- Extends `Features/FveDesigns` only; reads the catalog (`Features/Components`) via `db.Set<CatalogComponent>()`.
- **Compatibility** uses only catalog fields that exist today (`PowerW`): DC/AC ratio = panels x panelW / inverterW.
  Error when ratio < 0.8 or > 1.5; warning when ratio > 1.3 (clipping); panel count 1..1000.
  MPPT voltage / current limits and panel dimensions are NOT in the catalog -> not checked (flagged, see open questions).
- **Estimator**: `IYieldEstimator` (async; lat/lon, DC kWp, AC kW, roof planes) -> `YieldEstimate`
  (annual kWh, specific yield, source name). `SimpleYieldEstimator` is deterministic (latitude base yield x tilt/azimuth
  factor x shading, DC power split across planes by usable area, minus clipping loss). No HTTP calls; PVGIS or the ML
  service can replace it by registering another implementation.
- **Versioning**: new table `fve_design_versions` (FK -> `fve_designs`, unique `(design_id, version_number)`).
  Rows are immutable (private setters, no update/delete endpoint); component code/name/power/price are snapshotted.
  Saving requires design status `InDesign` and a compatible configuration. Unique violation on race -> 409.
- Schema: project uses `EnsureCreated` (no migrations), so a new entity configuration is enough.

## Endpoints (`/api/designs/{id}`)
| Method | Path | Roles | Result |
|---|---|---|---|
| POST | `/configuration/preview` | Designer, Admin | compatibility + estimate, nothing saved (200) |
| POST | `/versions` | Designer, Admin | saves immutable version (201); incompatible -> 400, wrong status / inactive component -> 409 |
| GET | `/versions` | Admin, Sales, Designer | list, newest first |
| GET | `/versions/{number}` | Admin, Sales, Designer | detail |
